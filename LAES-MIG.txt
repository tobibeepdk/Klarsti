KLARSTI – HJÆLP TIL ORD OG TAL

Sådan lægger du appen på GitHub med iPhone:

1. Pak zip-filen ud i appen Filer.
2. Åbn github.com i Safari og log ind.
3. Opret et nyt, offentligt repository.
4. Vælg Add file og derefter Upload files.
5. Upload alle filerne fra den udpakkede mappe.
6. Åbn repositoryets Settings → Pages.
7. Vælg Deploy from a branch, main og /(root). Gem.
8. Vent et par minutter. GitHub viser derefter adressen til appen.

På iPhone eller iPad:

1. Åbn den udgivne adresse i Safari.
2. Tryk på Del.
3. Vælg Føj til hjemmeskærm.

Du kan sende den udgivne adresse via Messenger.

Vigtigt:

- Klarsti sender ikke tekst eller regnestykker til en server.
- Kun visningsvalg gemmes på enheden.
- Oplæsning bruger enhedens stemme.
- Diktering afhænger af browseren og kan bruge browserens online taletjeneste.
  Du kan altid bruge mikrofonen på iPhone- eller iPad-tastaturet.
- Offlinebrug virker efter første besøg på den udgivne side.
